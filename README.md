# ECHO：无当地测流的跨河流水位预测

当前版本是第一阶段研究开发项目。气象经过区域 HBV 形成模拟流量，再利用许可历史水位推断当地响应。最终评价单位为米。

## 从这里开始

1. 阅读 [目录导航](00_项目说明/目录导航.md) 与 [研究权限](00_项目说明/研究任务与信息权限.md)。
2. 执行 `06_运行脚本/建立环境.ps1`，随后运行 `echo doctor`。
3. `echo download --list` 查看下载清单；`echo download --assets info attributes` 下载小文件。
4. 按 [数据准备说明](01_数据准备/README.md) 审计真实字段和水系，再开展训练。
5. `echo demo` 运行明确标注的合成端到端样例；它不代表真实水位性能。

所有命令也可以用 `python -m echo` 调用。使用 `echo --help` 查看接口。

## 当前研究边界

本地开发：单节点 HBV、标量地理、LSTM、单调曲线、16维动态状态和32维Gaussian地方代码。
正式 Mamba-3、空间图、局地地形编码、样条流和业务天气预报属于后续阶段；未接入时明确报错。

下载、数据与训练完成情况以 `本地运行/阶段状态.json` 和实际报告为准。代码存在不等于真实实验已完成。

2026-10-22启动进展：Python3.11.17、PyTorch2.8.0+cu126环境已实测，RTX3060 CUDA前向反向通过；info、属性、流域边界完成整包MD5校验。
Q/H完整归档现已完成官方MD5校验并提取；气象归档继续下载。
前20个真实Q/H文件已完成字段探查，其中13站支持期H覆盖达到80%；该前部样本不能代表最终开发集。
水位基准、时间支持和终端水系尚需进一步核验，尚无真实模型训练性能。

在PowerShell直接运行项目环境：`& .\本地环境\python.exe -m echo doctor`。
`06_运行脚本/查看运行状态.ps1`查看下载与接续审计；`恢复并行下载.ps1`在中断后继续。
`后台继续下载与审计.ps1`会以隐藏进程接续气象下载和审计，进程与日志位置保存在`本地运行/后台任务.json`；避免同时启动其他下载脚本写入同一资产。
官方HydroBASINS北美拓扑已下载并完成ZIP CRC与本地SHA256记录，匹配程序核验下游链条，实际覆盖以审计报告为准。
