# ECHO：无当地测流的跨河流水位预测

当前版本是第一阶段研究开发项目。气象经过区域 HBV 形成模拟流量，再利用许可历史水位推断当地响应。最终评价单位为米。

2026-10-24当前接续：以[全套资料与完整模型实施对照](00_项目说明/全套资料与完整模型实施对照_20261024.md)为准。本地与服务器固定同一主结构，先用8站做完整逻辑验证。Earthdata认证已打通，2011—2021原网格87,672小时下载已启动；首日24小时已为8站生成真实节点面积加权气象。42站独立静态属性与64维历史气候已整理，11块DEM续传中。A—E训练编排、参考缓存与来源校准已加入；完整真实空间输入和Linux官方Mamba运行仍待验收。

积雪储量和融雪已在HBV中实现；当前42站档案冰川覆盖字段均为0，原协议不要求额外冰川质量平衡模块。雪盖多年统计先作诊断，不能混入未核验年代的g。详见[完整资料库定义](01_数据准备/完整资料库定义_v1.yaml)。

状态入口：`06_运行脚本/查看完整模型资料状态.ps1`、`python -m echo.data.project_inventory`。当前42站站点汇总属性不等于增量节点属性，首日节点气象也不等于完整训练时段；完整输入尚未齐备的站点不计正式模型就绪。

前一轮4来源水系工程试跑存在骨干、空间数据/拓扑、HBV初始化、动态预热和训练目标等结构差异，**不能称为定稿协议一致的最终架构**。逐项差异和恢复门槛见[定稿协议一致性审计](00_项目说明/定稿协议一致性审计_20261023.md)，旧结果见[本地替代试跑](05_结果分析/正式架构小样本真实闭环_20261023.md)。

此前扩展开发版在三个开发站逐站等权RMSE：持续性0.881米、直接LSTM0.708米、静态ECHO0.549米、动态ECHO0.601米。动态尚未优于静态，事件RMSE仍以直接LSTM最低。它们不是新完整主模型的成绩，完整比较见[扩展ECHO闭环报告](05_结果分析/扩展ECHO确定性闭环_20261023.md)。

2026-10-23旧替代架构小样本低于已有动态ECHO和简单神经基线，且概率区间未校准；来源水系、训练episode偏少与结构替代均影响解释，不能据此判断最终模型结构。`06_运行脚本/查看运行状态.ps1`保留旧训练记录；完整主模型状态以上方2026-10-24实施对照为准。

## 从这里开始

1. 阅读 [完整启动计划](00_项目说明/第一阶段启动计划_原始完整.md)、[目录导航](00_项目说明/目录导航.md) 与 [研究权限](00_项目说明/研究任务与信息权限.md)。
2. 执行 `06_运行脚本/建立环境.ps1`，随后运行 `echo doctor`。
3. `echo download --list` 查看下载清单；`echo download --assets info attributes` 下载小文件。
4. 按 [数据准备说明](01_数据准备/README.md) 审计真实字段和水系，再开展训练。
5. `echo demo` 运行明确标注的合成端到端样例；它不代表真实水位性能。

所有命令也可以用 `python -m echo` 调用。使用 `echo --help` 查看接口。

## 当前研究边界

当前完整实现入口是`ProtocolECHO`及`echo.training.protocol_pipeline`，使用固定容量、官方Mamba适配器、真实空间输入契约与A—E阶段。训练控制测试与真实GPU/完整数据运行分开验收。用户已选择本机WSL2，F盘Ubuntu安装脚本、Linux依赖候选和官方GPU验收入口已准备，系统安装尚未执行；见[环境说明](07_环境配置/完整主模型Linux与WSL2准备.md)。
旧本地运行器使用缩小尺寸与自写SSM等替代实现，只保留为历史开发记录；不能用其结果替代新主模型的整年、多种子、受控消融和概率校准证据。

下载、数据与训练完成情况以 `本地运行/阶段状态.json` 和实际报告为准。代码存在不等于真实实验已完成。

2026-10-22进展：Python3.11.17、PyTorch2.8.0+cu126环境已实测，RTX3060 CUDA前向反向通过。首批五项数据已完整下载、官方MD5校验并提取；最新核验见[第二轮真实数据核验](05_结果分析/第二轮真实数据核验.md)。
