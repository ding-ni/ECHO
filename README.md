# ECHO：无当地测流的跨河流水位预测

当前版本是第一阶段研究开发项目。气象经过区域 HBV 形成模拟流量，再利用许可历史水位推断当地响应。最终评价单位为米。

最新主线：[多流域扩容与加量训练](00_项目说明/多流域扩容与加量训练计划.md)。已准备248个来源站、39个独立水系的Q预训练数据，采用每批32流域、30轮和原冻结三折开展联合训练；来源H站点资料同步批量扩展。

## 从这里开始

1. 阅读 [完整启动计划](00_项目说明/第一阶段启动计划_原始完整.md)、[目录导航](00_项目说明/目录导航.md) 与 [研究权限](00_项目说明/研究任务与信息权限.md)。
2. 执行 `06_运行脚本/建立环境.ps1`，随后运行 `echo doctor`。
3. `echo download --list` 查看下载清单；`echo download --assets info attributes` 下载小文件。
4. 按 [数据准备说明](01_数据准备/README.md) 审计真实字段和水系，再开展训练。
5. `echo demo` 运行明确标注的合成端到端样例；它不代表真实水位性能。

所有命令也可以用 `python -m echo` 调用。使用 `echo --help` 查看接口。

## 当前研究边界

本地开发：单节点 HBV、标量地理、LSTM、单调曲线、16维动态状态和32维Gaussian地方代码。
正式 Mamba-3、空间图、局地地形编码、样条流和业务天气预报属于后续阶段；未接入时明确报错。

下载、数据与训练完成情况以 `本地运行/阶段状态.json` 和实际报告为准。代码存在不等于真实实验已完成。

2026-10-22进展：Python3.11.17、PyTorch2.8.0+cu126环境已实测，RTX3060 CUDA前向反向通过。首批五项数据已完整下载、官方MD5校验并提取；最新核验见[第二轮真实数据核验](05_结果分析/第二轮真实数据核验.md)。
完整Q/H候选5767站，其中3056站有本批气象，1585站达到支持期80%及查询期90%的H覆盖门槛。边界复核发现140对跨终端重叠，42个冲突水系暂时隔离；其余候选经面积、气象和覆盖筛选剩422站、82个水系，仍需补齐水尺基准历史。
气象单位、UTC及累计区间已有官方依据。20站在两个支持期窗口通过USGS整点瞬时H对照；不能从旧Q脚本推断最新H为小时均值。统一采用步末时间参考，保留PET原始负值并显式记录非负蒸发需求变换。
第三轮已固定82个候选水系的完整角色（40训练、13验证、13开发评估、16盲测），并取得20站官方历史水尺稿。9个来源站已核对来源期Q/H，其中7站通过；按所有证据与预算生成首批8站清单。详见[第三轮站点放行与闭环](05_结果分析/第三轮真实站点放行与首批闭环.md)。完整100站、三种子与消融仍未验收。

已完成[首批真实基线对照](05_结果分析/首批真实基线对照.md)：1个验证站、2个开发评估站上两种基线均成功评分。两个开发站的等权MAE/RMSE为：持续性0.741/0.944米，区域HBV＋地方样条0.558/0.750米。一站改善、一站恶化，验证站RMSE略差；不能据此宣称总体收益。完整HBV及三折均已训练完成，8站参考Q通过逐站重算与检查点哈希核验；ECHO真实比较尚未完成。

详细结构见[模型结构与实现对照](00_项目说明/模型结构与实现对照.md)，实际接续安排见[后续执行与验收清单](00_项目说明/后续执行与验收清单.md)。两者分别列出定稿结构、当前开发替代、已经验证和仍待验证的内容。
